# SCOREFREE

Free, unofficial descriptive practice for PO aspirants.

## Official 2026 patterns

**IBPS PO/MT-XVI:** Essay + Comprehension, 2 questions, 25 marks, 30 minutes total.

**SBI PO 2026:** Emails (one of two), Situation Analysis (one of two), and either Report Writing or Precis Writing (one of two); 3 tasks, 50 marks, 30 minutes total.

Individual practice uses a 15-minute focused timer; this is a practice setting, not an official question-wise timing rule.

## Hosting on GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `app.js`, and `data.js`.
3. Go to Settings → Pages.
4. Select Deploy from a branch → main → /(root).
5. Save and open the generated Pages URL.
